# Object-Oriented Programming (OOP)

This folder contains Java programs demonstrating the fundamental concepts of Object-Oriented Programming.

### Concepts Covered
- **Abstract Classes:** Abstract classes and their implementation.
- **Interfaces:** Interface implementation, inheritance, and default methods.
- **Inheritance:** Multiple inheritance using interfaces.
- **Upcasting and Downcasting:** Converting references between parent and child types.
- **Objects:** Creating and working with objects.
- **Methods and Timers:** Main methods and an egg timer example.

### Language
- Java
