# Inner Classes

This folder contains Java programs demonstrating inner classes and related concepts.

### Concepts Covered
- **Inner Classes:** Defining classes inside other classes.
- **Non-Static Inner Classes:** Accessing members of the outer class through inner class objects.
- **Static Inner Classes:** Creating nested classes using the `static` keyword.
- **Local Inner Classes:** Defining classes inside methods.
- **Anonymous Classes:** Creating classes without explicitly naming them.
- **Effectively Final Variables:** Using local variables inside inner classes.
- **HashCode and `this`:** Understanding object hash codes and the `this` keyword.

### Language
- Java
