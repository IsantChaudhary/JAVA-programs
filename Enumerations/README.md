# Enumerations (Enums)

This folder contains Java programs demonstrating enumerations and their usage.

### Concepts Covered
- **Enums:** Defining and using predefined constants.
- **Enum and Switch:** Using enum constants with switch statements.
- **Enum Constructors:** Initializing enum constants using constructors.
- **Enum Methods:** Working with built-in and custom methods in enums.

### Language
- Java
